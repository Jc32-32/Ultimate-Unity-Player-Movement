This asset pack collection is meant for easy setup and use for UNITY ONLY projects. It is a rigidbody based movement system that is highly customizeable

Basic Inspector Setup:
// For Player
- Player (Player_Movement script, Rigid Body)
  - Player_Obj (Capsule collider, mesh)
  - Orientation (Transform)
  - Camera_Pos (Transform)
    
// For Camera
- Camera_Holder (Camera_Holder Script)
  - Camera_Pivot
    - Main_Camera (Camera_Movement Script)

NOTE: This asset pack uses unity's "new" input system and requires certain Input Actions to function properly. Make sure to have these input actions in your input settings and its corresponding keybind:
- Move
- Sprint
- Jump
- Crouch
Each of these are already instated in Unity's default player inputs, but make sure to add interactions to fit your game. E.X A hold interaction on sprint or jump.
